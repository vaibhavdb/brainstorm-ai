## 💾 Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/smart-dashboard.git

# Frontend setup
cd smart-dashboard/frontend
npm install
npm start

# Backend setup
cd smart-dashboard/backend
mvn clean install
mvn spring-boot:run
```
